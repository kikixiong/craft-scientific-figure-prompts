# Public, portable skill

- Keep this repository usable by any user. Shared instructions, documentation,
  examples and tests must not contain personal server aliases, private network
  names, account identifiers, IP addresses or machine-specific absolute paths.
- Use project-relative paths, the current user's home directory or descriptive
  placeholders. Discover image tools from the current agent's capabilities;
  do not assume access to the maintainer's services or infrastructure.
- Keep personal environment configuration, installation inventories and
  deployment reports outside this repository. Public change summaries should
  describe the shared capability without listing private deployment targets.
- Preserve required license attribution and canonical source links.
- Before publishing, review changed files for personal environment information
  and run the checks relevant to the change. Keep both READMEs aligned.
